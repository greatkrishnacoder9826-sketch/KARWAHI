## 💡 About the Project

**KARWAHI** is a personal AI companion project focused on creating a more natural and engaging conversational experience.

The project combines a web-based frontend, backend APIs, AI integration, and database services to build an interactive application.

My goal is to explore how AI can go beyond basic question-answering and become a more useful, personalized conversational companion.

## ✨ Key Highlights

- 🤖 **AI Integration:** Backend architecture for AI-powered conversations.
- 💬 **Interactive Interface:** A web-based frontend built with HTML, CSS, and JavaScript.
- 🧠 **Database Integration:** Supabase configuration for database-related functionality.
- ⚙️ **Backend API:** Node.js and Express-based backend.
- 🌐 **Live Deployment:** Frontend deployed on Cloudflare Pages and backend deployed on Render.
- 🔧 **Modular Structure:** Separate frontend, backend, database, and test directories.

*Note: Features available in the live version may differ from planned features.*

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/greatkrishnacoder9826-sketch/KARWAHI.git
cd KARWAHI
```

### 2. Configure the backend

```bash
cd backend
npm install
```

Create a `.env` file inside the backend directory and configure the environment variables required by the application.

Example:

```env
PORT=3000
GROQ_API_KEY=your_groq_api_key
SUPABASE_URL=your_supabase_url
SUPABASE_KEY=your_supabase_key
```

> Use the exact variable names expected by your source code. Never commit real API keys, passwords, or database secrets to GitHub.

### 3. Start the backend

```bash
npm run dev
```

### 4. Open the frontend

Run the frontend using your configured local development server and ensure its API base URL points to your local backend.

## 🔐 Environment Variables

KARWAHI may require environment variables for its AI provider, database connection, and server configuration.

- Keep credentials in `.env` files.
- Add secret files to `.gitignore`.
- Configure production secrets through your hosting provider's environment settings.
- Never expose private API keys in frontend JavaScript.
